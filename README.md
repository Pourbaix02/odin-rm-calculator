# SMARTWeight · landing

Esta página fue HeavyBar Calculator, una calculadora web de RMs y discos. Hoy la calculadora vive en la app **SMARTWeight** (Rainbow Tech) y esta web solo la anuncia, con los enlaces a las tiendas:

- App Store: https://apps.apple.com/app/id6837300043
- Google Play: https://play.google.com/store/apps/details?id=com.rainbowtech.smartweight

Las capturas de `public/screens` salen de `store/capturas/raw` del repo de la app.

```bash
npm install
npm run dev
npm run build
```

Se despliega en Vercel (`odin-rm-calculator.vercel.app`) con cada push a `main`.
